화성 탈출기 계정·데이터 삭제 안내

개발자: Strophic Games · 앱 ID: com.strophic.marsescape

삭제되는 정보

  • 구글 로그인을 통해 연결된 계정 정보(이메일, 이름, 고유 ID)
  • 클라우드(Firebase Cloud Firestore)에 저장된 게임 진행 데이터

기기에 저장된 진행 데이터는 앱을 삭제하면 함께 삭제됩니다.

방법 1. 앱 안에서 삭제 (권장)

  1. 앱을 실행하고 오른쪽 위 설정을 누릅니다.
  2. 구글 계정 항목에서 로그인 상태를 확인합니다.
  3. 계정·데이터 삭제 버튼을 누르고 확인창에서 계속을 선택합니다.
  4. 클라우드 저장 데이터와 계정 연결이 즉시 삭제됩니다. 이 작업은 되돌릴 수 없습니다.

방법 2. 이메일로 삭제 요청 (앱을 쓸 수 없는 경우)

  1. strophicgames@gmail.com 로 메일을 보냅니다.
  2. 제목: "화성 탈출기 데이터 삭제 요청", 본문에 로그인에 사용한 구글 계정 이메일을 적고 해당 계정에서 보내 주세요(본인 확인).
  3. 확인 후 영업일 기준 7일 이내에 삭제하고 회신합니다.

보관되는 정보

삭제 후에는 법령상 보관이 필요한 정보를 제외하고 개발자가 보관하는 이용자 정보는 없습니다. 광고 식별자는 기기의 설정 → Google → 광고에서 직접 재설정하거나 삭제할 수 있으며, Google AdMob이 처리하는 광고 데이터는 Google 정책에 따릅니다.
